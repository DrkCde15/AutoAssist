Documentação da API

Tudo o que você precisa para integrar o AutoAssist ao seu sistema.

Base URL: https://api.autoassist-l9lr.onrender.comFormato: JSONAuth: Bearer Token

Autenticação

Todas as requisições devem incluir o header Authorization: Bearer <token>.

POST/api/b2b/authAutenticar e obter token de acesso

Diagnóstico

Envie uma imagem e receba um diagnóstico estruturado com causas, severidade e sugestões.

POST/api/b2b/diagnosis

Parâmetros

Nome Tipo Obrigatrio Descrio
image file Sim Imagem do painel ou componente (JPEG/PNG, max 10MB)
vehicle_make string No Marca do veículo (ex: Toyota)
vehicle_model string No Modelo do veículo (ex: Corolla)
vehicle_year number No Ano do veículo (ex: 2020)

Checkout

Crie uma sesso de pagamento para seus clientes.

POST/api/b2b/checkoutCriar sesso de pagamento

Leads

Liste os leads capturados pela sua integração.

GET/api/b2b/leadsListar leads capturados

Limites do plano

Plano Chamadas Preo
Starter 1.000/ms R$ 49,90/ms
Business 10.000/ms R$ 199,90/ms
Enterprise 20.000+/ms Sob consulta

Exemplo completo (cURL)

terminal 
curl -X POST https://api.autoassist-l9lr.onrender.com/api/b2b/diagnosis \
  -H "Authorization: Bearer sk_live_xxx" \
  -H "Content-Type: multipart/form-data" \
  -F "image=@painel.jpg" \
  -F "vehicle_make=Toyota" \
  -F "vehicle_model=Corolla" \
  -F "vehicle_year=2020"

SDKs e exemplos

Python

import requests

response = requests.post
  "https://api.autoassist-l9lr.onrender.com/api/b2b/diagnosis",
  headers={"Authorization":"Bearer sk_live_xxx"},
  files={"image": open"painel.jpg","rb"}}

data = response.json()
